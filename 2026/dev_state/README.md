# Zimbabwe Tech Industry Survey

This repository contains the source code, configuration, and documentation for the **Zimbabwe Tech Industry Survey**.

The survey aims to collect anonymous insights from people working or aspiring to work in the technology sector in Zimbabwe. The results will be published as an **open dataset** to support transparency, research, policy discussions, and community-driven decision-making.

---

## 🎯 Purpose

The main goals of this survey are to:

* Understand the current state of Zimbabwe’s tech industry
* Capture data on education background and learning paths
* Identify commonly used programming languages, frameworks, and tools
* Explore cloud and AI adoption within the local tech ecosystem
* Provide open, anonymized data for developers, researchers, startups, and policymakers

We believe access to real data leads to better conversations, better opportunities, and a healthier tech ecosystem.

---

## 🧠 Who Should Participate

This survey is intended for:

* Software developers
* IT professionals
* Data scientists and ML practitioners
* Students and aspiring developers
* Tech founders and freelancers

Participation is **anonymous**, and no personally identifiable information is collected.

## 📊 Data & Transparency

Once the survey closes:

* Responses will be cleaned and anonymized
* Results will be published as an **open dataset**
* Summary insights and visualizations may also be shared

The dataset will be free for anyone to use for:

* Research
* Blog posts and analysis
* Product decisions
* Policy discussions

## 🛠 Tech Stack

* Frontend: JavaScript, HTML, CSS
* Backend: Node.js
* Database: Supabase
* Deployment: Vercel Cloud
